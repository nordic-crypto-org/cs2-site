Why this demo

This is a demo of a new way to sponsor LAN parties:

  1. Players win voucher tokens, such as WATER, by playing.
  2. At the event's cafeteria, a player redeems a voucher by melting the token on-chain.
  3. After the event, the CS2 admin or the sponsor settles the bill with the cafeteria. The bill is based on how many tokens were redeemed (melted) on-chain.

This runs on Nexa testnet only. The tokens have no real value. The demo is run by Nordic Crypto.

How vouchers work

Vouchers are issued as Nexa testnet tokens (WATER, PIZZA or BURGER) when you win in-game, following the rules for each game mode below. Automatic awards are limited to 4 per player per rolling hour.

To receive vouchers, link your Steam account to a Wally wallet once. It takes about a minute:

  1. Install Wally on your phone or computer and create a Nexa testnet account (addresses start with nexatest:).
  2. Join a server and type !nexa in chat. The server prints a short link and a code.
  3. Open the link in any browser. The page shows a QR code. Phone: scan it with Wally. Wally Desktop: press Copy link request on the page, select your testnet account in Wally and press the paste button on its home screen.
  4. Confirm in Wally. It sends your testnet receive address and nothing else. It does not ask for a name or an email. The game chat confirms when you are linked.
  5. Win. If you win before linking, the voucher is held and issued once you link.

Only your SteamID64, your Nexa address and timestamps are stored for the link. Vouchers are testnet tokens only; mainnet issuance is switched off in the code.

About the plugin

Nexa Vouchers is an open-source (MIT) CounterStrikeSharp plugin for Counter-Strike 2 dedicated servers, with a Cloudflare Worker backend.

  • Each award is signed with HMAC-SHA256; the backend checks the signature and rejects replays and stale timestamps.
  • Network setting: testnet, regtest or mainnet. Mainnet is a stub that refuses to issue.
  • Tested in CI, including a regtest end-to-end suite against a local Nexa node.

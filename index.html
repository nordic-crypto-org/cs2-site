How vouchers will work (coming soon)

Voucher awards are not issuing yet. The plugin is installed in testnet mode, but the voucher backend is not live, so !nexa linking and awards do not work today. When it goes live, it works like this:

  1. Join the server and type !nexa in chat.
  2. Open the link the server prints. It shows a nexid:// link for a Nexa wallet. It does not ask for a name or an email.
  3. Approve the signature in your wallet. The address must be a Nexa testnet address (nexatest:).
  4. Win. If you win before linking, the voucher is held and issued once you link.

Only your SteamID64, your Nexa address and timestamps are stored for the link. On testnet, a voucher is a demo record in the backend (labelled pizza, burger or water); it is not a mainnet token. Mainnet issuance is switched off in the code.

About the plugin

Nexa Vouchers is an open-source (MIT) CounterStrikeSharp plugin for Counter-Strike 2 dedicated servers, with a Cloudflare Worker backend.

  • Each award is signed with HMAC-SHA256; the backend checks the signature and rejects replays and stale timestamps.
  • Network setting: testnet, regtest or mainnet. Mainnet is a stub that refuses to issue.
  • Tested in CI, including a regtest end-to-end suite against a local Nexa node.
